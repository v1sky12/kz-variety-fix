# kz_variety_fix — V7.17 / 19 октября 2026

Roblox KZ для ПК с движением по формулам CKZ. Скачать [ZIP](https://github.com/v1sky12/kz-variety-fix/raw/upload/kz-variety-fix-updated/kz_variety_fix_updated.zip) или [RBXL](https://github.com/v1sky12/kz-variety-fix/raw/upload/kz-variety-fix-updated/kz_variety_fix.rbxl), затем открыть RBXL в Roblox Studio.

## Исправлено

- **Surf:** исправлена потеря скорости на переходе brush-рамп с разным углом: погрешность касательного sweep выбирала боковую стенку следующего brush. Переходы проверяются на двух уклонах, трёх масштабах и трёх поворотах. Также сохранены предыдущие исправления Core, направления скорости и предела на крутом склоне.
- **Столкновения:** повторные контакты с одной плоскостью объединяются; отступ на collision skin не добавляет скорости. До восьми контактов за тик позволяют пройти несколько граней. Сохраняется восстановление микропересечения до 2 CS units. Неизменные primitive brushes повторно используются после respawn; изменение размера или CFrame сбрасывает кеш.
- **Bhop / duck:** perf больше не зависит от валидности jumpstats; воздушный duck меняет высоту стоп по разнице Source hull; исправлены границы anti-bhop и конфликт force duck/unduck.
- **Клиент и сервер:** передаются виртуальная скорость, высота hull и взгляд. Сервер проверяет землю footprint 32 units и пробой 2 units, включая край платформы, с порогом нормали .7; другие игроки исключены. Проверяются порядок motion-пакетов, персонаж, serial, высота и направление. Это клиентский мотор с серверными триггерами; серверного переигрывания команд пока нет.
- **Телепорты:** CP сохраняет yaw и pitch в момент нажатия C; V восстанавливает их стандартной камерой. Сохранены точная позиция Warp, перенос скорости при любом порядке Warp/атрибута, короткие TP и относительное смещение по стопам.
- **Специальные блоки:** абсолютные push-оси Source преобразуются даже на повёрнутой карте; абсолютный компонент имеет приоритет над добавлением в том же тике. Учитываются задержка, cooldown и cancel-on-teleport; новая попытка очищает push-состояние. Отложенные I/O и push выполняются хронологически.
- **Триггеры и таймер:** входы и выходы обрабатываются в порядке пересечения вдоль пути, независимо от порядка сущностей. Старт/финиш получают интерполированный серверный момент пересечения. Учитываются немедленные Source I/O, задержки и фактическое время нахождения в trigger_push. Очистка CP картой сохраняет TP-счётчик текущего забега, как в открытом CKZ.
- **Лестницы:** отрыв с удерживаемым Space работает и после подхода с уже нажатой клавишей; одиночный wheel-jump расходуется. LAJ начинает дистанцию и время от точки отрыва. Проверено боковое движение по протяжённой лестнице. Захват передаётся серверу для сброса bhop-состояния.
- **Вода:** изменение поверхности сохраняет дно; глубина по щиколотку допускает ходьбу, по пояс включает плавание. Убрано двойное air/water-ускорение, добавлен выход на низкий край с проверкой препятствия и просвета сверху.
- **Jumpstats:** sync включает dead air, strafes считаются по смене направления поворота. Поправка момента приземления убирает ошибку раннего snap к полу; промах публикуется на пересечении плоскости старта, а WJ сохраняется после схода с края.
- **Запуск и сборка:** fallback снимает mutex перед запуском резервного мотора. Сборщик редактирует разобранные Source-массивы и проверяет, что геометрия, структура и резервные скрипты не изменены. Установщик полностью проверяет контейнер и атомарно заменяет файл с уникальной резервной копией.

V5, `KZBrush_V1` и запасной мотор сохранены. Стандартный контроллер камеры Roblox сохранён; экранные кнопки не добавлены. Версия основного мотора видна в атрибуте `KZMovementBuild=2026-10-19-r2` у HumanoidRootPart.

## Проверки

- 83 исполняемых сценария Luau: 46 для движения/карты, 10 для клиентского контроллера, 27 для серверных обработчиков.
- 12 Python-тестов контейнера и установки: в том числе повреждённая длина Source, UTF-8, прерванная замена, резервные копии и откат.
- Полная проверка RBXL: 1869 чанков, 135676 объектов, 428 Source-полей; компиляция всех 428 скриптов.
- ZIP проверяется по CRC и побайтовому совпадению вложенного RBXL.
- Rojo 7.7.1 независимо десериализовал полный RBXL через `rbx_binary`, без изменения карты.

В тестах заменены сервисы Roblox и типы Vector3/CFrame; исполняется код настоящих модулей, клиентских и серверных обработчиков. Roblox Studio в этой среде недоступен. Нативные MeshPart-запросы, реальная репликация двух игроков и прохождение исходной рампы требуют [проверки в Studio](PLAYTEST_RU.md). Совпадение с частными настройками CYBERSHOKE не подтверждено.

## Исходные специальные блоки

Список восстановлен из 718 исходных сущностей: 9 single bhop, 8 multibhop, 12 teleport-триггеров типа 10, 11 push, 2 modifier и 8 anti-bhop. Последовательных bhop-триггеров типа 13 в исходной карте нет; их обработка проверяется отдельным сценарием.

[Аудит блоков](special_blocks_audit.json) содержит ID, границы в CS units, назначения, задержки, условия push, абсолютные оси и множители. Он является инвентаризацией исходных данных, а не отметкой о прохождении каждого блока в Studio.

## Разработка

Нужны Python 3.11+, пакет из `requirements.txt`, `make`, C++17-компилятор и инструменты Luau. Проверенная версия Luau: `9d7748a4f324213a18cb8283fa2a77c330225fa0`.

```bash
python -m pip install -r requirements.txt
python -B -m unittest discover -s tests -p 'test_*.py' -v
python -B run_luau_tests.py --luau /path/to/luau
python -B build_place.py --luau-compile /path/to/luau-compile
python -B build_place.py --check --luau-compile /path/to/luau-compile
# Дополнительная проверка независимым парсером:
python -B build_place.py --check --rojo /path/to/rojo
```

Редактируются файлы в `src/`, ID и пути привязаны в `src/manifest.json`. После сборки изменённые Source проверяются на совпадение с файлами. `build_place.py` отказывается менять любые другие свойства или скрипты вне manifest. В GitHub Actions добавлен тот же набор проверок.
